Privacy Policy: FactZap Helper

Last updated: November 24, 2026

FactZap Helper is a private tool used only by the owner of the FactZap YouTube channel. It is not offered to the public.

What it accesses

With the channel owner's permission (Google OAuth, scope youtube.force-ssl), the tool reads comments on FactZap's own videos, posts comments and replies as FactZap, and likes FactZap's own videos.

What it stores

The OAuth token is stored only on the channel owner's own computer. No data is sold, shared with third parties or used for advertising. Public comment text is read only to reply to viewers on FactZap's videos.

Google API Services

FactZap Helper's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact
